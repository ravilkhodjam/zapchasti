# zapchasti — сайт компании

Статический сайт без сборки и внешних JavaScript-зависимостей.

## Запуск

Откройте `index.html` в браузере. Для локальной проверки через сервер можно выполнить из этой папки `python3 -m http.server 8000` и открыть `http://localhost:8000`.

## Перед публикацией

1. Заполните объект `SITE` в начале `script.js`: города, телефон, полную ссылку WhatsApp вида `https://wa.me/77001234567` и email. Название сейчас установлено как `zapchasti`.
2. Замените реквизиты в подвале `index.html`, проверьте тексты о направлениях и способах работы.
3. Замените фотографию `assets/engine-hero.jpg` на согласованную фотографию компании или товара. Сейчас используется нейтральная [фотография Erik Mclean на Unsplash](https://unsplash.com/photos/a-close-up-of-a-car-engine-pREObTHk3b8).
4. Уточните текст `privacy.html` под реальную компанию и порядок обработки заявок. При подключении сервера или аналитики обновите политику.

Пока WhatsApp и email не указаны, форма проверяет поля и предлагает скопировать заявку. Она не имитирует успешную отправку.
